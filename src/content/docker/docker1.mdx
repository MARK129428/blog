# 安装docker

 
<CodeBlock language="bash">{`
# 添加官方源
sudo yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo


`}</CodeBlock>

<CodeBlock language="bash">{`
# 安装 Docker Engine
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
`}</CodeBlock>

<CodeBlock language="bash">{`
# 启动 Docker
# 启动 Docker 服务
sudo systemctl start docker

# 设置开机自启
sudo systemctl enable docker
`}</CodeBlock>

# 配置阿里云docker源

找到阿里云镜像加速器 [https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors](https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors)

配置 Docker Daemon
<CodeBlock language="bash">{`
 
 
# 验证加速器是否生效
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://xxxx.mirror.aliyuncs.com"]
}
EOF
sudo systemctl daemon-reload
sudo systemctl enable docker
sudo systemctl restart docker

# docker 安装 MySQL

## 拉取镜像
<CodeBlock language="bash">{`
docker pull mysql:8.0
`}</CodeBlock>
## 创建具名数据卷
<CodeBlock language="bash">{`
docker volume create mysql-data-volume

docker volume ls | grep mysql-data-volume
`}</CodeBlock>
## 运行 MySQL 容器并挂载 Volume
<CodeBlock language="bash">{`
docker run --name mysql-vol-dev \
-p 3306:3306 \
-e MYSQL_ROOT_PASSWORD=YourSecurePassword \
-v mysql-data-volume:/var/lib/mysql \
--restart always \
-d mysql:8.0
`}</CodeBlock>
## 命令行登录
 
<CodeBlock language="bash">{`
docker exec -it mysql-vol-dev mysql -u root -p
`}</CodeBlock>

OK, MySQL 安装完成了。
