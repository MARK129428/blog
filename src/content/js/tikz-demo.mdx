## 基础图形

用 TikZ 画一个矩形和圆：

```tikz
\begin{tikzpicture}
  \draw[->, thick] (0,0) -- (2,0) -- (2,2) -- (0,2) -- cycle;
  \node at (1,1) {Hello TikZ};
  \fill[blue!50] (3.5,1) circle (0.8);
  \node at (3.5,1) {A};
\end{tikzpicture}
```

## 函数图像

使用 pgfplots 绘制抛物线：

```tikz
\begin{tikzpicture}
  \draw[->] (-2.5,0) -- (2.5,0) node[right] {$x$};
  \draw[->] (0,-1.5) -- (0,3.5) node[above] {$y$};
  \draw[domain=-2:2, smooth, variable=\x, blue, thick] plot ({\x}, {\x*\x});
  \node at (1.5,2.5) {$y = x^2$};
\end{tikzpicture}
```

## 流程图

简单的流程示意：

```tikz
\begin{tikzpicture}[
  box/.style={rectangle, draw, minimum width=2cm, minimum height=0.8cm, rounded corners}
]
  \node[box] (A) {Start};
  \node[box, below=1cm of A] (B) {Process};
  \node[box, below=1cm of B] (C) {Output};
  \draw[->] (A) -- (B);
  \draw[->] (B) -- (C);
\end{tikzpicture}
```

## 树结构

```tikz
\begin{tikzpicture}[
  level distance=1.5cm,
  level 1/.style={sibling distance=3cm},
  level 2/.style={sibling distance=1.5cm}
]
  \node {Root}
    child { node {A}
      child { node {A1} }
      child { node {A2} }
    }
    child { node {B}
      child { node {B1} }
      child { node {B2} }
    };
\end{tikzpicture}
```
